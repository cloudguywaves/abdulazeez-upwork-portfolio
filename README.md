# Abdulazeez Abdulganiyu — Portfolio

Professional portfolio for project management, operations management, supply chain coordination, workflow automation, CRM, and cloud operations support.

## Project structure

```text
abdulazeez-portfolio/
├── index.html       # Main page (kept at repository root for GitHub Pages)
├── css/
│   └── style.css    # Responsive layout, visual design, and component styles
├── js/
│   └── script.js    # Mobile navigation and automatic copyright year
└── README.md        # Project overview and maintenance notes
```

## Run locally

Open `index.html` in a browser. For a more reliable local preview, use a lightweight development server such as VS Code Live Server.

## Publish with GitHub Pages

In the repository settings, open **Pages** and configure deployment from the `main` branch and `/(root)`. Keep `index.html` at the repository root so GitHub Pages can find the homepage.

## Maintenance notes

- Keep styling in `css/style.css` and browser behavior in `js/script.js`.
- Update navigation anchors when section IDs change in `index.html`.
- The portfolio currently uses three Google Drive thumbnail URLs for photographs. If those images are moved to local assets later, update the image paths in `index.html` and verify public access.
- Use clear, focused commit messages that describe one change at a time.
